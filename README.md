University Course Registration System
Overview
This Java-based Course Registration System is designed to automate university course enrollment, management, and reporting. The project leverages Object-Oriented Programming (OOP) principles, Java serialization, CSV file parsing, and role-based access control to provide a seamless experience for both students and administrators.

Features
🔹 Admin Functionality:
Create, edit, and delete courses (except course ID and name).
Register new students and manage their enrollments.
View and sort all courses, full courses, and students in a course.
Generate and export reports of full courses using file handling.
🔹 Student Functionality:
View available courses and register for them.
Withdraw from registered courses.
View personal course enrollment history.
🔹 System Highlights:
Role-Based Access Control: Secure login system for admins and students.
Data Persistence: Uses Java serialization and CSV parsing for efficient storage and retrieval.
Error Handling: Robust exception handling prevents data corruption and ensures stability.
Sorting & Reporting: Dynamic sorting of courses based on enrollment numbers.
Technologies Used
Java (OOP: Inheritance, Polymorphism, Encapsulation, Abstraction)
Data Structures (ArrayLists, Sorting)
File I/O & Serialization (CSV parsing, binary serialization for persistence)
Exception Handling (Prevents system crashes from invalid input and file errors)
